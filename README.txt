THE OCEAN VOYAGE — Birthday Website (v2)

ISI
- index.html : struktur halaman + isi letter (sesuai teks client, tidak diubah)
- style.css  : tampilan cinematic ocean, responsif HP/tablet/desktop
- script.js  : intro, laut animasi (canvas), suara ombak, parallax, kembang api
- audio/song.mp3 : lagu latar (diambil dari video client), otomatis loop
- fonts/     : font Cormorant Garamond & DM Sans (sudah lokal, tidak butuh internet)

CARA PAKAI
1. Ekstrak ZIP, biarkan semua file/folder tetap satu folder.
2. Buka index.html di browser (Chrome/Safari terbaru). Bisa juga di-upload ke hosting statis (Netlify, GitHub Pages, dll).

CATATAN
- Lagu + suara ombak baru menyala setelah tombol "Mulai Pelayaran" ditekan, karena aturan autoplay browser.
- Kapal berupa ilustrasi SVG buatan sendiri (tidak ada aset berlisensi).
- Teks intro/hero/bagian lain bebas diubah di index.html; jangan ubah teks di dalam <article class="log"> kecuali client minta.
